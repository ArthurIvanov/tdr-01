# Функциональные требования: A11y Contrast Checker (Figma-плагин)

Статус: **согласовано, реализовано** (P0 + P1 + FR-16; FR-15, FR-33, FR-34 отложены)
Версия документа: 0.2

## 1. Цель и аудитория

**Цель.** Убрать из работы дизайнера ручную проверку контраста и ускорить исправление: найти нарушения WCAG на макете и исправить их в один клик, не выходя из Figma.

**Аудитория.** Продуктовые и UI-дизайнеры, дизайн-системные команды, ревьюеры макетов перед хендоффом.

## 2. Исследование рынка (Figma Community)

Источники: обзоры, а не страницы плагинов. Цены и состав функций нужно перепроверить в Community перед финальным решением.

| Плагин | Что делает | Выводы для нас |
|---|---|---|
| **Stark** | Самый широкий набор: контраст, симулятор зрения, focus order, ландмарки, alt-текст, touch targets. Freemium, по отзывам почти всё платное (Pro от ~$60/мес.). | Эталон по охвату, но дорогой и навязывает апгрейд. Наше преимущество: бесплатный и сфокусированный. |
| **A11y – Color Contrast Checker** | Проверяет контраст всего видимого текста во фрейме, уровни AA и AAA. | Базовый сценарий «просканировать фрейм». Отзывы отмечают, что на сложных слоях бывают неверные результаты. Это наш главный риск и главное отличие: корректный расчёт фона. |
| **Contrast (WillowTree)** | Бесплатный, массовая проверка, WCAG и бета-APCA. | Подтверждает спрос на массовую проверку и APCA как второй режим. |
| **Adee** | Контраст, 8 сценариев дальтонизма, touch targets, генерация alt-текста. | Многофункциональный, но не фокусируется на исправлении. |
| **ColorContrast** | Скан фрейма, APCA, симуляция дальтонизма, исправление в один клик. | Ближайший по духу конкурент. Источник отзыва — сам вендор. |
| **Visual Contrast** | Фокус на APCA, предпросмотр текста, подсказка цветов. | APCA востребован, но пока не нормативен. |
| **Color Blind** | Бесплатный симулятор 8 типов дальтонизма. | Не наш охват, возможное развитие. |
| **A11y Focus Orderer** (Microsoft) | Аннотации порядка фокуса и табуляции. | Другая задача, в MVP не входит. |

**Вывод.** Рынок насыщен общими комбайнами, и ни одна категория не закрыта идеально. Слабые места конкурентов, на которые мы целимся:
1. Неточный расчёт фона на сложных слоях (подложки, прозрачность, вложенность).
2. Исправление либо платное, либо грубое: меняет оттенок или не учитывает прозрачность.
3. Нет прозрачного объяснения, почему слой пропущен.

**Позиционирование.** Быстрый, точный и бесплатный проверщик контраста с безопасным автоисправлением.

## 3. Уже реализовано (MVP)

- FR-01 Проверка текстовых слоёв по выделению или по всей странице.
- FR-02 Расчёт WCAG 2.x: порог 4.5:1 для обычного текста, 3:1 для крупного (≥24px, либо ≥18.66px при жирности ≥700).
- FR-03 Определение фона: родители, нижние соседние слои, полупрозрачные заливки, цвет страницы.
- FR-04 Текст с несколькими стилями: проверка по фрагментам.
- FR-05 Учёт opacity слоя и всех родителей.
- FR-06 Автоисправление (Fix и Fix all): сдвиг к чёрному или белому с сохранением оттенка, один шаг Undo.
- FR-07 Список нарушений с переходом к слою, прогресс, пустые состояния, тёмная тема, доступность с клавиатуры.

## 4. Предлагаемые требования (для согласования)

Приоритеты: **P0** — войдёт в релиз 1.0, **P1** — желательно в 1.0, **P2** — после.

### 4.1 Точность проверки
| ID | Требование | Приоритет |
|---|---|---|
| FR-10 | Уровни соответствия **AA / AAA** переключаются в UI (AAA: 7:1 и 4.5:1 для крупного). По умолчанию AA. | P0 |
| FR-11 | Нетекстовые элементы (иконки, границы полей, состояния компонентов): порог 3:1 по WCAG 1.4.11. Включается переключателем. | P1 |
| FR-12 | Фон-градиент: проверка по худшей точке (ближайшая к цвету текста опорная точка градиента) с пометкой «приблизительно». | P1 |
| FR-13 | Фон-изображение: слой не отбрасывается молча, а помечается «Требует ручной проверки» с причиной. | P0 |
| FR-14 | Эффективная прозрачность родителей учитывается и для слоёв-подложек. | P1 |
| FR-15 | Текст, перекрытый частично несколькими подложками: проверка по каждой пересекающейся подложке, вывод худшего значения. | P2 |
| FR-16 | Режим **APCA** как справочный, отдельным столбцом, без влияния на статус «прошёл/не прошёл». | P2 |

### 4.2 Исправление
| ID | Требование | Приоритет |
|---|---|---|
| FR-20 | Fix сохраняет привязку к стилю или переменной цвета, если она была: предлагает выбор «изменить стиль/переменную» или «отвязать и применить цвет». | P0 |
| FR-21 | Подтверждение при массовом Fix all, если затронуто больше N слоёв (N по умолчанию 20), с предпросмотром списка. | P1 |
| FR-22 | Вариант исправления на выбор: «затемнить/осветлить текст» или «изменить фон». | P1 |
| FR-23 | Fix всегда обратим одним Undo. | P0 |

### 4.3 Работа с результатами
| ID | Требование | Приоритет |
|---|---|---|
| FR-30 | Фильтры списка: по степени нарушения, по типу (обычный/крупный текст), по фрейму. | P1 |
| FR-31 | Игнорирование отдельных слоёв (исключение сохраняется в `setPluginData` слоя) и возврат из игнорирования. | P1 |
| FR-32 | Экспорт отчёта: CSV и Markdown (слой, текст, цвета, коэффициент, порог, ссылка на узел). | P1 |
| FR-33 | Создание аннотаций на холсте рядом с нарушением (метка с коэффициентом) и их удаление. | P2 |
| FR-34 | Повторный автоскан при изменении выделения (по настройке, по умолчанию выключено). | P2 |

### 4.4 UX и доступность самого плагина
| ID | Требование | Приоритет |
|---|---|---|
| FR-40 | Локализация интерфейса: RU и EN (по языку Figma). | P1 |
| FR-41 | Контраст и клавиатурная доступность UI плагина соответствуют WCAG AA. | P0 |
| FR-42 | Сводка результата: «N нарушений из M проверенных; K пропущено» со ссылкой на причину пропуска. | P0 |

## 5. Нефункциональные требования

- **NFR-01 Производительность:** страница на 5 000 текстовых слоёв сканируется без зависания UI; прогресс обновляется не реже раза в секунду.
- **NFR-02 Приватность:** работа полностью офлайн, `networkAccess: none`, содержимое файла нигде не сохраняется и не передаётся.
- **NFR-03 Безопасность изменений:** без явного действия пользователя плагин ничего не меняет в документе.
- **NFR-04 Права:** манифест с минимальными правами, `documentAccess: dynamic-page`.
- **NFR-05 Качество:** формулы покрыты юнит-тестами (эталонные пары из спецификации WCAG), `npm run build` и `npm run lint` без ошибок.
- **NFR-06 Точность:** расхождение с эталонным калькулятором WCAG не более 0.01 по коэффициенту.

## 6. Вне охвата

Порядок фокуса, ландмарки, генерация alt-текста, симуляция дальтонизма, размеры touch targets, проверка заголовков. Это возможное развитие, но не 1.0.

## 7. Критерии приёмки релиза 1.0

1. Все требования P0 реализованы и проверены вручную на тестовом файле (фреймы с подложками, прозрачностью, смешанным текстом, градиентом, картинкой).
2. На эталонном наборе из 20+ пар цветов результат совпадает с онлайн-калькулятором WCAG.
3. Fix и Fix all откатываются одним Undo.
4. Слои с неразрешимым фоном видны в отчёте с причиной.

## 8. Принятые решения

1. AAA — да, переключатель AA / AAA.
2. Нетекстовые элементы (FR-11) — да, в 1.0.
3. APCA — да, справочный столбец (FR-16).
4. Модель распространения — бесплатно.
5. Локализация RU / EN — сразу.
